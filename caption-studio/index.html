Posting

Caption endpoint

The tool never holds an AI key. It posts photos to a small proxy, which adds the key and calls the model. To run your own, setup takes about ten minutes with the included Code.gs script.

  1. Open script.google.com, new project, paste proxy/Code.gs.
  2. Project Settings → Script Properties: add ANTHROPIC_API_KEY and PROXY_TOKEN (any long random string).
  3. Deploy → New deployment → Web app, execute as Me, access Anyone. Copy the /exec URL.
  4. Paste the URL and the same token below, then Test.

Settings live only in this browser. Export to move them to another phone or hand a finished setup to a client. The export includes the proxy token, so share it like a password.
